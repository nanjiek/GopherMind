# P6.1：医疗文档解析、分块与证据分级

## 目标

P6 不把“文件转成一大段文本，再按固定长度切开”视为医疗 RAG。文档进入知识库前必须先确定真实格式、来源、适用范围和结构；检索出的每个证据块必须能说明它来自哪里、对谁适用、是否仍有效、能否支持临床类回答。

这项能力服务于 P6 的权威知识治理。向量库只能帮助召回候选块，不能决定事实状态、来源等级或是否可以用于高风险回答。

## 共同入口与不可省略的元数据

上传扩展名只能作为提示，不能作为格式判断。摄取服务先做 MIME/魔数识别、恶意文件检查、解析器版本记录和内容哈希，再交给相应解析器。所有解析结果归一为文档树：文档 ID、原始文件哈希、文档类型、语言、标题路径、页码或工作表、表格/图片/脚注位置、发布日期、版本、生效和失效时间、发布机构、适用人群、访问范围、OCR 置信度与解析器版本。

每个块都必须继承这些来源字段，并额外记录 `chunk_id`、顺序、内容哈希、前后文边界和分块策略版本。不能只存原文和向量；缺少来源定位、版本或范围的块不能作为高风险建议的证据。

## 按格式和医学语义分块

| 文档类型 | 解析重点 | 分块单位 | 必须保留的上下文 |
| --- | --- | --- | --- |
| 临床指南、专家共识、监管规范、医疗白皮书 | 标题树、推荐语句、推荐等级、流程图、表格、版本与生效日期 | 一个完整小节；推荐语句与其适用条件、证据等级、例外条件不可拆开；表格和流程图整体保留 | 发布机构、版本、章节路径、页码、推荐等级、适用人群、有效期 |
| 系统综述、Meta 分析、随机对照试验、观察性研究 | 摘要、研究设计、样本、干预、结局、局限性、结论 | 按论文语义章节切；结果必须和研究对象、样本量及研究设计相连 | DOI/出处、研究类型、发表日期、研究人群、样本量、结局、局限性 |
| 药品说明书、药监公告、用药指南 | 适应症、剂量、给药途径、禁忌症、不良反应、特殊人群、相互作用 | 以完整药物章节为最小单位；剂量表、肝肾调整、孕哺和禁忌症不能与药名拆开 | 药品通用名、剂型、监管地区、版本、生效日期、适用年龄/人群 |
| 病历、出院小结、病程记录、转诊信 | 就诊时间线、诊断、主诉、医嘱、既往史、责任主体 | 按一次就诊、一次病程记录或一段时间线切；不把不同患者或不同就诊拼接 | 患者/机构授权范围、就诊时间、记录类型、作者角色、原始文件定位 |
| 检验报告、生命体征、影像报告 | 项目、数值、单位、参考范围、异常标记、采样时间、结论 | 一个检验面板或一次报告为一个结构化块；影像所见与印象一起保存 | 检验时间、单位、参考区间、仪器/机构、报告状态、影像页码 |
| CSV、Excel、JSON、FHIR 等结构化数据 | 表头、字段含义、对象关系、时间、单位与编码体系 | 按一条临床事件、一个资源对象或有共同表头的一小组行切；禁止孤立切单个数值 | 表头/字段路径、编码体系、时间范围、单位、数据源、工作表/行号 |
| Markdown、网页、知识库页面 | 标题层级、链接、引用、修订时间 | 按标题树和完整段落切；列表、警告框、引用与所属标题一起保留 | URL、抓取时间、作者/机构、修订时间、标题路径、引用链接 |
| 扫描 PDF、图片、图表 | OCR 文本、版面、页码、表格和图注 | 先 OCR 和版面分析，再按页面区域和语义块切；低置信 OCR 不单独成为证据 | 页码、区域坐标、OCR 置信度、图表标题、原图哈希 |

普通新闻、营销材料、论坛内容和来源不明网页可以作为低等级背景材料，但不得单独支撑诊断、剂量、禁忌症或紧急处置建议。

## 证据等级和可用性

每个块除格式外还要有独立的证据身份。建议使用 A 至 E 五档：A 为监管机构和现行正式指南；B 为系统综述、Meta 分析和高质量随机对照试验；C 为观察性研究、叙述性综述或机构材料；D 为白皮书、厂商材料、新闻和一般知识网页；E 为患者私有文件，它能描述该患者的记录，但不能自动成为通用医疗结论。来源不明、过期、OCR 置信度不足或解析失败的内容只可留存审计，默认不可用于回答。

Evidence Agent 的输出必须是“证据包”，而不是一段没有出处的摘录：原文片段、文档/块 ID、页码或章节、版本、证据等级、适用条件、时间有效性与不确定性。Safety Agent 再检查来源等级、版本、患者范围、剂量单位和人群是否匹配。高风险回答至少需要可定位的 A/B 级依据，或明确转人工；不能因为语义相似就把 D/E 级材料说成确定的医疗事实。

## 检索和权限边界

检索先按 tenant、用户、患者/机构授权和文档状态过滤，再做语义召回。之后按相关性、证据等级、版本新鲜度和适用人群重排；已撤回、过期、删除、未确认或不在授权范围内的块必须在模型看到前过滤。患者私有文档与公共知识库分域存储、分域检索，不能因为相似度高而跨患者或跨机构返回。

任何解析、OCR、嵌入、外部索引同步或模型摘要都属于外部效果：执行前都要通过 Capability 边界重新授权。PostgreSQL 先保存文档版本、解析状态、证据状态和索引意图；事务 Outbox 再驱动向量索引。不得以向量库已写入来认定文档已可用。

## 验收与非目标

验收至少覆盖：同一结论在指南、论文、药品说明书和患者记录中被正确分类；表格、剂量、参考范围、页码和章节路径不丢失；过期指南和低置信 OCR 不参与高风险回答；撤回或越权块即使还留在向量库也不能被召回；不同患者的病历绝不互相检索；分块策略升级可按内容哈希增量重建，并保留旧版本以回滚。

本节点不导入旧 MySQL 文档或记忆，不做双写、CDC、回填，也不允许模型自动把文档内容写成 confirmed 病史。动态 Agent 委派不属于本节点。
