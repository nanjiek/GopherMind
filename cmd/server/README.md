# 包说明

## 包作用
- 负责应用启动与依赖组装，保证服务按固定顺序初始化。
- 统一处理进程启动校验与优雅退出。

## 实现逻辑
1. 读取运行配置并做关键参数校验。
2. 初始化日志、指标、追踪、数据层、消息层和模型层依赖。
3. 装配业务服务与接口路由并启动服务监听。
4. 接收退出信号后按顺序释放资源。

## 关键接口
```go
func main()
func validateAuthConfig(cfg config.AuthConfig) error
```

## 协作关系
- 依赖配置模块提供参数。
- 依赖接口层提供对外路由。
- 依赖存储、模型与消息模块提供能力。
